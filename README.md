<h1>Dental Offer Maker Google Sheets</h1>

<h2>Description</h2>
<p>
  Dental Offer Maker Google Sheets is a WordPress plugin that automates the creation of dental plan offers. It connects to a Google Sheets document via API to extract pricing information, dynamically generates a form with the relevant price fields, and allows users to create personalized dental plans. After submission, users are redirected to a preview page where they can review and download the dental plan as a PDF using Google Chrome.
</p>

<h2>Features</h2>
<ul>
  <li><strong>Google Sheets Integration</strong>: Extracts up-to-date pricing data directly from a Google Sheets document using the Google Sheets API.</li>
  <li><strong>Dynamic Form Generation</strong>: Automatically generates a form with price fields based on the extracted data, making it easy to create custom dental plan offers.</li>
  <li><strong>PDF Export</strong>: After generating a dental plan, users can preview the offer and download it as a PDF using Google Chrome.</li>
</ul>

<h2>Installation</h2>
<ol>
  <li>Download the plugin ZIP file.</li>
  <li>Install and activate the plugin on your WordPress site.</li>
  <li>Configure the Google Sheets API settings within the plugin.</li>
</ol>

<h2>Usage</h2>
<ol>
  <li>Set up your Google Sheets document with the necessary pricing information.</li>
  <li>Use the plugin to connect your Google Sheets document to WordPress.</li>
  <li>Generate and customize dental plan offers through the dynamically created forms.</li>
  <li>After submission, review the plan on the preview page and download it as a PDF.</li>
</ol>
